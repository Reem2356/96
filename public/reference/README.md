# ضع الصورة المرجعية هنا

ضع ملف الصورة الرسمية والمصرَّح باستخدامها لخادم الحرمين الشريفين
الملك سلمان بن عبدالعزيز آل سعود باسم:

```
king-salman.jpg
```

في نفس هذا المجلد (`public/reference/`). يُفضّل صورة مربعة أو قريبة من
المربع، بدقة 1000×1000 بكسل فأعلى، بصيغة jpg أو png.

لا حاجة لتعديل أي كود — سيتم اكتشاف الملف وتحميله تلقائيًا من
`src/lib/referenceImage.ts` بمجرد وضعه هنا. حتى إضافته، يعرض الموقع نمطًا
بديلاً تجريبيًا (بورتريه مجرّد) حتى لا يتعطل التطوير أو العرض.
