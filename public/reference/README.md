# الصورة المرجعية

الصورة الرسمية المستخدمة حاليًا كمرجع للوحة الفسيفساء موجودة هنا باسم:

```
king-salman.webp
```

لاستبدالها بصورة أخرى: ضع الملف الجديد بنفس الاسم `king-salman.webp` في
هذا المجلد (`public/reference/`)، أو غيّر اسم الملف وحدّث الثابت
`REFERENCE_IMAGE_PATH` في `src/lib/referenceImage.ts` ليطابقه. يُفضّل
صورة مربعة أو قريبة من المربع بدقة عالية.

لا حاجة لأي تعديل آخر — سيتم تحميل الملف تلقائيًا. إن حُذف الملف، يعرض
الموقع نمطًا بديلاً تجريبيًا (بورتريه مجرّد) حتى لا يتعطل التطوير أو العرض.
